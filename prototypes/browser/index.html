EXPERIMENT / OPTICAL DATA TRANSFER

Optical Link Lab

ファイルを色の格子に変えて、画面から受け取る。専用形式の送受信実験です。

01 / 送信

ファイルを選ぶとコードを生成します。

自動再生は最後まで表示したあと繰り返します。受信が揃うまで送信を続けてください。全画面表示はEscで終了できます。

02 / 受信

プレビューをドラッグすると範囲を指定できます。ピンクの外枠の外端から外端までを選んでください。

0 / 0 フレーム
送信側の画面や保存した画像を読み取ります。
復元したファイルを保存

カメラは正面撮影を前提にした実験機能です。まず96×96・白黒または4色・1〜2 fpsで、画面を大きく映してください。斜め撮影・自動回転には未対応です。
