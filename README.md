# Draco Transfer

画面に表示したパターンを読み取ってファイルを転送する実験プロジェクト。

QRコードの規格には縛られず、色・図形・空間周波数・時間方向の変化を比較していきます。用途や最終方式はまだ固定せず、まず動くものを作り、測って判断します。高性能端末向けの高密度・高速復号も検討しますが、その優位性は未検証です。

## まず動かす

Node.js 18以上。外部パッケージのインストールは不要です。

```sh
npm start
```

ブラウザで [http://localhost:8787](http://localhost:8787) を開き、「デモファイルを用意」→「画像経由で自己テスト」を押してください。128 KiBのファイルを画像から復元し、SHA-256の一致を確認できます。Windowsでは `prototypes/browser/start.cmd` でも起動できます。

現在の試作は白黒・4色・16色の格子方式です。送信GUIと、PNG・画面共有・カメラの受信GUIがあります。カメラ入力は実験機能で、実機での安定したファイル転送はまだ検証していません。Androidネイティブ受信アプリは未実装です。

画面共有・カメラ・PNGでの操作手順は [試作の説明](prototypes/browser/README.md) にまとめています。スマートフォンのカメラ受信にはHTTPSでの配信が必要で、付属のlocalhostサーバーだけでは別端末からアクセスできません。

## 検証と計測

```sh
npm test
npm run bench
```

`npm test` は誤り訂正、9種類の格子設定、2 MiBのランダムデータの画像往復を検証します。`npm run bench` は合成画像で復号の各処理を測定し、JSONを標準出力へ出します。後者は端末間の転送速度やカメラ性能の測定ではありません。
